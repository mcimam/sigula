TABS
The selected tab is marked by both a heavier label and an underline, so the current view is obvious at a glance.
NAVIGATION
Plain nouns, never jargon, in a fixed order. With dozens of destinations, the list is broken into named groups that collapse, and a search box sits above them — typing filters every group at once. The current page is tinted and coloured, not just bolded. On a phone there is no bottom bar: the same grouped list opens as a full-height menu from the header, with the most recent pages pinned at the top.

MODAL / DIALOG
The title asks the question, the body says what will happen, and the buttons repeat the actual actions — never just “OK” and “Cancel”. The safe option is always on the left. Dialogs that hold a form or a table can be resized: drag the bottom-right corner, or the right and bottom edges. Size is remembered per dialog, the body scrolls rather than the page, and the header and footer stay put.

PAGINATION
Built for hundreds of pages. The number strip always shows the first page, the last page and the pages either side of the current one, with gaps in between, so it never grows past one row. Rows per page is the user's choice and is remembered; the jump box goes straight to a page number. Every target is 44px, and the written position is always in view.
